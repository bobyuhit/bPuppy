# bPuppy 硬件连接

## ESP32-S3 WROOM-1 N16R8 GPIO 分配

### 1. 舵机 (8 路, LEDC PWM)

| 舵机 | GPIO | 通道 | 说明 |
|------|------|------|------|
| LF_HIP | 1 | ch0 | 左前大腿 |
| LF_KNEE | 2 | ch1 | 左前小腿 |
| LH_HIP | 47 | ch2 | 左后大腿 |
| LH_KNEE | 21 | ch3 | 左后小腿 |
| RF_HIP | 42 | ch4 | 右前大腿 |
| RF_KNEE | 41 | ch5 | 右前小腿 |
| RH_HIP | 45 | ch6 | 右后大腿 |
| RH_KNEE | 48 | ch7 | 右后小腿 |

- PWM 频率: 50Hz
- 脉宽范围: 500-2500μs (0°-180°)
- 外设: LEDC, TIMER_0

| 信号 | GPIO |

| SCL | 14 |

- 电平: 3.3V

### 3. 烧录串口 (UART0)

| 信号 | GPIO |
|------|------|
| RX | 43 |
| TX | 44 |
| 波特率 | 115200 |

- 电平: 3.3V
- 用途: 固件烧录 + REPL 控制台

---

### 4. 通信串口 (UART2)

| 信号 | GPIO |
|------|------|
| RX | 19 |
| TX | 20 |
| 波特率 | 115200 (默认) |

- 电平: 3.3V
- 用途: CI-33T 语音模块 / micro:bit 通信
- 上电自动初始化

---

### 5. 摄像头复用串口 (UART1)

| 信号 | GPIO | 摄像头原功能 |
|------|------|-------------|
| RX | 18 | CAM D5 (Y7) |
| TX | 17 | CAM D6 (Y8) |

- 电平: 3.3V
- **与摄像头共享引脚，不拍照时可用作串口**
- 需手动初始化: `bpuppy_uart.u1_init(17, 18, 115200)`

### 串口汇总

| 串口 | 管脚 | 用途 | 初始化 |
|------|------|------|--------|
| UART0 | RX=43, TX=44 | 烧录 + REPL 控制台 | 系统自动 |
| UART1 | RX=18, TX=17 | 摄像头复用通信 | 手动 `u1_init(17, 18, ...)` |
| UART2 | RX=19, TX=20 | 默认通信 (CI-33T/micro:bit) | 上电自动 |

---

### 6. ADC 电压测量

| 信号 | GPIO | 外设 |
|------|------|------|
| 电压采集 | 38 | ADC1_CH2 |

- 衰减: 11dB (量程 ~0-3.1V)
- 12-bit 精度
- 上电自动初始化
- 用法: `bpuppy_adc.read_mv()` → 返回毫伏值
- **电池测量**: 7.4V LiPo → 分压 (10k+3.3k) 后接 GPIO 38, 软件乘系数

## 外部设备连接

### CI-33T 语音模块

```
CI-33T                    ESP32-S3
───────                   ────────
VCC (5V)  ───────────→   外部供电
GND       ───────────→   GND
PB5 (TX)  ───────────→   GPIO 19 (UART2 RX)
PB6 (RX)  ←───────────   GPIO 20 (UART2 TX)
```

- 电平: 两边都是 3.3V IO，直连
- 波特率: 115200

### micro:bit

```
micro:bit (金手指)        ESP32-S3
─────────────────        ────────
3V        ←──── 3.3V LDO 输出 (外部供电，不直连 ESP32)
GND       ──── GND
TX        ───→ GPIO 19 (UART2 RX)
RX        ←─── GPIO 20 (UART2 TX)
```

- 电平: 两边都是 3.3V IO，直连
- micro:bit 金手指 3V 脚只能接 3.3V，不要接 5V

### 5V I2C 设备

```
ESP32 (3.3V)             5V 设备
───────────     ┌───    ───────
GPIO3  ──── SDA ─┤TXS   SDA ── 5V I2C 设备 A
GPIO14 ──── SCL ─┤0104  SCL ── 5V I2C 设备 B
                 └───
```

- 需要双向电平转换 (TXS0104E / PCA9306)
- 3.3V 侧 + 5V 侧各配上拉电阻

### 电池电压测量

| 元件 | 参数 | 接脚 |
|------|------|------|
| R1 (上分压) | 33kΩ | 电池正极 ↔ GPIO 38 |
| R2 (下分压) | 10kΩ | GPIO 38 ↔ GND |
| 采样点 | — | GPIO 38 (ADC1_CH2) |

```
电池 7.4V 正极
     │
  R1 33kΩ
     │
     ├───→ GPIO 38 (ADC1_CH2)
     │
  R2 10kΩ
     │
    GND

R1∥R2      = 7.7kΩ       (远小于 ADC 推荐 10kΩ, 采样准)
分压比     = 10/43 ≈ 0.233
满电 8.4V → ADC 约 1.96V
标称 7.4V → ADC 约 1.72V
低电 6.6V → ADC 约 1.53V
漏电流     ≈ 7.4V / 43kΩ ≈ 0.17mA
软件公式   = read_mv() × 4.3
```

## 供电架构

```
电池 7.4V (2S LiPo)
  │
  ├─→ 5V LDO ─┬─→ ESP32-S3 VIN (5V)
  │            ├─→ CI-33T VCC (5V)
  │            └─→ 舵机电源 (5-7.4V 直供)
  │
  └─→ 3.3V LDO ──→ micro:bit 金手指 3V (如需)
```
