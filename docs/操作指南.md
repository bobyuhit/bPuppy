# bPuppy 操作指南

## 一、编译 (Docker 容器内)

```bash
# 进入容器 (容器名根据 docker ps 查看)
docker exec -it <容器名> bash

# 加载 ESP-IDF 环境
source /opt/esp/idf/export.sh

# 首次编译 (或改了 cmake/sdkconfig)
rm -rf build && idf.py set-target esp32s3 && idf.py build

# 日常增量编译 (仅改了 .c / .py)
idf.py build
```

> **已在容器内:** 跳过 `docker exec`，直接 `source /opt/esp/idf/export.sh && idf.py build`

产物: `build/micropython_bpuppy.bin`

> **一行搞定 (编译 + 拷贝 + 烧录，替换容器名和COM口):**
> ```powershell
> cd C:\Users\<用户名>; docker exec <容器名> bash -c "source /opt/esp/idf/export.sh && cd /workspace && idf.py build"; docker cp <容器名>:/workspace/build/bootloader/bootloader.bin .; docker cp <容器名>:/workspace/build/partition_table/partition-table.bin .; docker cp <容器名>:/workspace/build/micropython_bpuppy.bin .; esptool --chip esp32s3 --port COM10 --baud 115200 write-flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 micropython_bpuppy.bin
> ```

## 二、烧录 (Windows PowerShell)

ESP32-S3 使用原生 USB-JTAG CDC，烧录前需将芯片置于下载模式（按住 BOOT 再按 RESET，或使用自动下载电路）。

```powershell
# 先切到用户目录
cd C:\Users\<用户名>

# 拷贝固件
docker cp <容器名>:/workspace/build/bootloader/bootloader.bin .
docker cp <容器名>:/workspace/build/partition_table/partition-table.bin .
docker cp <容器名>:/workspace/build/micropython_bpuppy.bin .

# 烧录 (115200 约 3 分钟, 稳定)
esptool --chip esp32s3 --port COM10 --baud 115200 write-flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 micropython_bpuppy.bin
```

仅拷贝+烧录 (已编译完):
```powershell
cd C:\Users\<用户名>; docker cp <容器名>:/workspace/build/bootloader/bootloader.bin .; docker cp <容器名>:/workspace/build/partition_table/partition-table.bin .; docker cp <容器名>:/workspace/build/micropython_bpuppy.bin .; esptool --chip esp32s3 --port COM10 --baud 115200 write-flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 micropython_bpuppy.bin
```

> **提示:** 看到三行 `Wrote xxx bytes` + `Hash of data verified` 即烧录成功。烧完按 RESET 或重新上电。

## 三、串口连接

- 波特率: **115200**
- 端口: **COM10** (USB-JTAG CDC，直连 USB 即可)
- 工具: PuTTY / Tera Term / VS Code Serial Monitor

> ESP32-S3 原生 USB-JTAG，不需要外接 USB-UART 转接器。插上 USB 线后 Windows 自动识别为串口。

烧录后重启，应看到:
```

  Build: Jul 10 2026 xx:xx:xx
  WROOM-1 N16R8 | uPy v1.22.1 | IDF v5.1.2
============================================
  Loaded:   servo, uart, motion
Ready.
>>>
```

## 四、MicroPython 命令

### bpuppy_servo — 舵机控制

**舵机命名常量:**

| 常量 | 值 | 含义 |
|------|-----|------|
| `bpuppy_servo.LF_HIP` | 0 | 左前大腿 |
| `bpuppy_servo.LF_KNEE` | 1 | 左前小腿 |
| `bpuppy_servo.LH_HIP` | 2 | 左后大腿 |
| `bpuppy_servo.LH_KNEE` | 3 | 左后小腿 |
| `bpuppy_servo.RF_HIP` | 4 | 右前大腿 |
| `bpuppy_servo.RF_KNEE` | 5 | 右前小腿 |
| `bpuppy_servo.RH_HIP` | 6 | 右后大腿 |
| `bpuppy_servo.RH_KNEE` | 7 | 右后小腿 |

**函数:**

| 函数 | 参数 | 说明 |
|------|------|------|
| `init_all()` | 无 | 按硬件映射初始化全部 8 路舵机 |
| `set_angle(channel, deg)` | 通道号, 角度(0-180) | 设置舵机角度 |
| `get_angle(channel)` | 通道号 | 返回当前角度 (float) |
| `stop()` | 无 | 紧急停止所有舵机 (关闭 PWM) |
| `cal(channel, ref_deg)` ★ | 通道, 参考角 | 校准存 NVS |
| `get_cal(channel)` | 通道 | 读取校准参考角 (float) |
| `load_cal()` ★ | 无 | 从 NVS 加载校准值 (开机自动调用) |

**舵机校准:**

`cal(ch, ref)` → 舵机转到 `ref`° 当场验证 + 存 `offset = ref - 90` 到 NVS。之后每次 `set_angle(90)` 都自动加这个 offset，腿自然垂直。反复调、覆盖生效。`get_cal(ch)` 查看当前值。

### bpuppy_motion — 运动控制

**函数:**

| 函数 | 参数 | 说明 |
|------|------|------|
| `start()` | 无 | 启动 50Hz 运动控制任务（自动调用 `load_geometry()`） |
| `stand_up()` | 无 | 蹲→站缓动过渡 (C 层, 8舵机同步) |
| `set_gait(gait)` | 步态名称 (str) | 切换步态 |
| `emergency_stop()` | 无 | 急停 |
| `resume()` | 无 | 恢复运动 |
| `show_geometry()` | 无 | **查看**全部持久化参数 + 运行时参数当前值 |
| `load_geometry()` | 无 | 从 NVS 重新加载持久化参数（start 自动调用） |

**持久化参数（NVS 存储，掉电保留，★标记）：**

| 组 | 函数 | 参数 | 默认值 |
|----|------|------|--------|
| 几何 | `cal_ik(L1, L2)` ★ | 大腿长, 小腿长 (mm) | 40, 45 |
| 几何 | `set_body_dims(bl, bw)` ★ | 前后髋半距, 左右髋半宽 (mm) | 62.5, 59 |
| 几何 | `set_joint_limits(hmin, hmax, kmin, kmax)` ★ | 髋下限, 髋上限, 膝下限, 膝上限 (deg) | 0, 180, 10, 170 |
| 舵机 | `bpuppy_servo.cal(ch, ref)` ★ | 8 路舵机校准参考角 (deg) | 均为 90 |
| 重心 | `set_center(offset)` ★ | 脚中位偏移 (mm)，正=前移 | 0 |

> 以上 9+8=17 个参数设定后自动写入 NVS，`motion.start()` 自动恢复。`show_geometry()` 可查看全部。无 NVS 数据时回退 `ik.h` 宏默认值。

**运行时参数（掉电丢失，需每次设置，无 NVS）：**

| 函数 | 参数 | 默认值 | 说明 |
|------|------|--------|------|
| `set_params(speed, stride, height)` | 步频, 步幅+方向 (mm), 高度 (mm) | 2.5, 0, 70 | speed=0停, stride正=前负=后 |
| `set_lift(lift)` | 抬腿高度 (mm) | 30 | |
| `set_omega(omega)` | 基准角频率 (rad/s) | 2.0 | 调步态快慢 |
| `set_body_pose(roll, pitch, yaw)` | 横滚, 俯仰, 偏航 (deg) | 0, 0, 0 | 身体倾角 |
| `set_turn(turn)` | -1~+1 | 0 | 转弯系数 |

**实测最优参数:**

| 步态 | speed | stride | height | lift | pose | 备注 |
|------|-------|--------|--------|------|------|------|
| walk | 2.5 | 70 | 60~70 | 30 | pitch=-5 | 猫步, 稳而安静 |
| trot | 8~8.5 | 50~70 | 60~70 | 30 | pitch=-3 | 小跑, 最快 |

**步态列表:**

| gait 参数 | 说明 |
|-----------|------|
| `"stand"` | 站立不动 |
| `"walk"` | 猫步 (speed>0前进, speed<0后退) |
| `"trot"` | 小跑 (speed>0前进, speed<0后退) |
| `"go"` | 自适应 (推荐): speed≤4→walk, speed≥6→trot, 4~6 全参数插值 |
| `"crouch"` | 蹲伏 (四腿折叠, 关机前放松) |
| `"sit"` | 猫坐 (前腿撑, 后腿折) |
| `"play"` | 邀玩 (前低后高 + 4Hz摇臀8次) |

## 五、快速上手

上电**自动站立**，无需手动指令。站起来后直接操作：

```python
# === 走路 ===
bpuppy_motion.set_params(2.5, 70, 60)     # (speed, stride, height) stride正=前
bpuppy_motion.set_gait("walk")            # 猫步前进

bpuppy_motion.set_params(3, -70, 60)      # 猫步后退 (stride负=后)
bpuppy_motion.set_gait("walk")

bpuppy_motion.set_params(8, 50, 70)       # 小跑
bpuppy_motion.set_gait("trot")

bpuppy_motion.set_params(7, 70, 60)       # 中速自适应
bpuppy_motion.set_gait("go")

# 转向
bpuppy_motion.set_turn(-0.5)              # 左转 -1~+1

# 停下
bpuppy_motion.set_gait("stand")

# 蹲伏休息
bpuppy_motion.set_gait("crouch")
```

> 关机前先 `set_gait("crouch")` 让舵机放松。

### 持久化参数校准 (首次或换硬件后 ★NVS)

设定后自动写入 NVS，重启无需重设。`start()` 自动恢复。

```python
import bpuppy_motion
import bpuppy_servo

# === 几何参数 — 通常无需改动 ===
bpuppy_motion.cal_ik(40, 45)                     # 腿长 (L1, L2 mm)
bpuppy_motion.set_body_dims(62.5, 59)            # 髋距 (前后半距, 左右半宽 mm)
bpuppy_motion.set_joint_limits(0, 180, 10, 170)  # 限位 (髋min/max, 膝min/max deg)

# === 舵机校准 — 逐腿操作 ===
bpuppy_motion.emergency_stop()                   # 先停运动
bpuppy_servo.cal(bpuppy_servo.LF_HIP, 95)        # 反复调 cal 直到腿垂直, 覆盖即可
# ... 逐条校准其余 7 路 ...
bpuppy_motion.resume()                           # 恢复运动

# === 重心偏移 — 走起来后微调 ===
bpuppy_motion.set_center(0)                      # 正值=脚前移 (重心后移)

# 查看全部
bpuppy_motion.show_geometry()

### 速查卡片

```python
# ===== 启动 =====
import bpuppy_motion
bpuppy_motion.start()                          # 启动 50Hz 运动任务
bpuppy_motion.stand_up()                       # 蹲→站缓动过渡 (约3秒)

# ===== 运行时参数 (每次上电需重设) =====
bpuppy_motion.set_params(2.5, 70, 60)          # (speed, stride, height) stride正=前
bpuppy_motion.set_gait("walk")                 # 猫步前进
bpuppy_motion.set_params(8, 50, 70)
bpuppy_motion.set_gait("trot")                 # 小跑
bpuppy_motion.set_gait("go")                   # 自适应 (推荐)
bpuppy_motion.set_gait("stand")                # 站立
bpuppy_motion.set_gait("crouch")                  # 蹲伏
bpuppy_motion.set_gait("sit")                     # 猫坐
bpuppy_motion.set_gait("play")                    # 邀玩 (前低后高+摇臀)
bpuppy_motion.set_params(3, -70, 60)           # 后退 (stride 负号)
bpuppy_motion.set_turn(-0.5)                   # 左转 -1~+1
bpuppy_motion.set_omega(3.0)                   # 加速
bpuppy_motion.set_body_pose(0, -5, 0)          # 身体前倾 (roll, pitch, yaw)
bpuppy_motion.set_lift(30)                     # 抬腿高度

bpuppy_motion.emergency_stop()                 # 急停!!
bpuppy_motion.resume()                         # 恢复

# ===== 持久化参数 (★NVS, 一次设定永久生效) =====
bpuppy_motion.cal_ik(40, 45)                   # ─┐ 几何
bpuppy_motion.set_body_dims(62.5, 59)          # ─┤
bpuppy_motion.set_joint_limits(0,180,10,170)   # ─┘
bpuppy_motion.set_center(-10)                  # ── 重心
bpuppy_motion.show_geometry()                  # 查看全部

# ===== 舵机控制 =====
import bpuppy_servo
# 常量: LF_HIP=0 LF_KNEE=1 LH_HIP=2 LH_KNEE=3 RF_HIP=4 RF_KNEE=5 RH_HIP=6 RH_KNEE=7
bpuppy_servo.set_angle(bpuppy_servo.LF_HIP, 90) # 立即驱动
bpuppy_servo.get_angle(bpuppy_servo.LF_HIP)     # 读取角度
bpuppy_servo.cal(bpuppy_servo.LF_HIP, 94)       # ★校准存NVS, 反复调直到腿垂直
bpuppy_servo.stop()                             # 关闭PWM

# ===== 常用组合 =====
# 最快
bpuppy_motion.set_params(8.5, 70, 60)
bpuppy_motion.set_lift(45)
bpuppy_motion.set_gait("trot")

# 这也不错
bpuppy_motion.set_params(8.5, 50, 70)
bpuppy_motion.set_lift(30)
bpuppy_motion.set_gait("trot")

# 最稳
bpuppy_motion.set_params(2.5, 70, 70)
bpuppy_motion.set_lift(30)
bpuppy_motion.set_gait("walk")

## 六、步态仿真 (PC 端)
在烧录前可用 PC 端 Python 脚本预览和验证步态。位于 `gait_sim/` 目录。

### 依赖

```bash
pip install matplotlib numpy
```

### 用法

```bash
cd gait_sim

# 一键输出 CSV + PNG + GIF
python gait_sim.py

# 弹出图表窗口
python gait_sim.py --show

# 自定义参数
python gait_sim.py --stride 80 --height 70

# 调整动图速度
python gait_sim.py --fps 4

# 只输出特定格式
python gait_sim.py --no-csv --no-png    # 只要 GIF
python gait_sim.py --no-gif --no-png    # 只要 CSV
```

### 输出文件

| 文件 | 内容 |
|------|------|
| `gait_walk.csv` | 单周期 200 帧 × 22 列 (足端坐标 + 关节角度) |
| `gait_walk.png` | t-Z 曲线 + t-X 曲线 + 顶视图快照 + 相位甘特图 |
| `gait_walk.gif` | 顶视图动图 (支撑多边形 + 重心 + 足端轨迹) |

### CSV 列说明

| 列 | 含义 | 坐标系 |
|----|------|--------|
| `step` | 帧序号 | — |
| `g_phase_deg` | 全局相位 (°) | — |
| `{leg}_fx` | 足端前后位置 | x=0 为髋, 正=前 |
| `{leg}_fz` | 足端高度 | z=0 为地面, 正=上 |
| `{leg}_hip` | 髋舵机角度 (°) | 0~180 |
| `{leg}_knee` | 膝舵机角度 (°) | 10~170 |
| `{leg}_swing` | 摆动/支撑 | 1=摆动, 0=支撑 |

### 图表说明

**t-Z 图** — 四足高度随时间变化。z=0 为着地，弧线为抬腿。

**t-X 图** — 四足前后位置随时间变化。x=0 为髋正下方，正=前伸。

**顶视图** — 身体矩形 + 四足位置 + 支撑多边形 (斜线填充) + 重心 (十字)。
- 重心绿色 = 在支撑面内 (稳定)
- 重心红色 = 超出支撑面 (不稳定)
- 三角 = 抬脚 (摆动相)
- 圆点 = 着地 (支撑相)

**相位甘特图** — 四腿摆动/支撑时间分布。红=swing, 绿=stance。

## 七、摄像头操作

### 拍照

```python
import bpuppy_camera

# 初始化（上电后首次需手动 init）
bpuppy_camera.init()

# 拍照 → 返回 (data, width, height, format)
data, w, h, fmt = bpuppy_camera.capture()
# data: JPEG 字节数据（默认 1600×1200）
# fmt:  4=JPEG, 1=RGB565, 5=GRAYSCALE

# 释放
bpuppy_camera.deinit()
```

### PC 端一键拍照

ESP32 上电后，在 PC 终端运行：

```powershell
pip install pyserial
cd tools
python capture.py COM10
```

连接后按 **Enter** 拍照（自动保存并打开图片预览），输入 **q** 退出。全程不重启 ESP32。

> 原理: PC 串口发送 `import camera_serial; camera_serial.snap()` → ESP32 拍照 → base64 回传 → PC 解码保存为 JPEG。

### 格式切换

默认 `init()` 输出 JPEG 1600×1200。如需其他格式或分辨率：

```python
# QVGA 320×240 RGB565（色球识别用）
bpuppy_camera.init_adv(bpuppy_camera.QVGA, 0, 2, 20000000, bpuppy_camera.RGB565)

# SVGA 800×600 JPEG（WiFi 图传用）
bpuppy_camera.init_adv(bpuppy_camera.SVGA, 10, 2, 20000000, bpuppy_camera.JPEG)
```

| 分辨率 | 常量 | 像素 |
|--------|------|------|
| 160×120 | `QQVGA` | — |
| 320×240 | `QVGA` | — |
| 640×480 | `VGA` | — |
| 800×600 | `SVGA` | — |
| 1024×768 | `XGA` | — |
| 1600×1200 | `UXGA` | 默认 |

| 格式 | 常量 | 用途 |
|------|------|------|
| JPEG | `JPEG` (4) | 拍照/图传，硬件编码 |
| RGB565 | `RGB565` (1) | 图像识别，原始像素 |
| GRAYSCALE | `GRAYSCALE` (5) | 灰度图 |

### 已知问题

- 初始化后前几帧可能是旧画面（双缓冲残留），`camera_serial.snap()` 已自动丢弃前 3 帧
- 图像上下颠倒：已在驱动中通过 `set_vflip(1)` 修正
