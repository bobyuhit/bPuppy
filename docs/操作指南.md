# bPuppy 操作指南

## 一、编译 (Docker 容器内)

```bash
# 进入容器 (容器名根据 docker ps 查看)
docker exec -it <容器名> bash

# 加载 ESP-IDF 环境
source /opt/esp/idf/export.sh

# 首次编译 (或改了 cmake/sdkconfig)
rm -rf build && idf.py set-target esp32s3 && idf.py build

# 日常增量编译 (仅改了 .c / .py)
idf.py build
```

> **已在容器内:** 跳过 `docker exec`，直接 `source /opt/esp/idf/export.sh && idf.py build`

产物: `build/micropython_bpuppy.bin`

> **一行搞定 (编译 + 拷贝 + 烧录，替换容器名和COM口):**
> ```powershell
> cd C:\Users\<用户名>; docker exec <容器名> bash -c "source /opt/esp/idf/export.sh && cd /workspace && idf.py build"; docker cp <容器名>:/workspace/build/bootloader/bootloader.bin .; docker cp <容器名>:/workspace/build/partition_table/partition-table.bin .; docker cp <容器名>:/workspace/build/micropython_bpuppy.bin .; esptool --chip esp32s3 --port COM10 --baud 115200 write-flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 micropython_bpuppy.bin
> ```

## 二、烧录 (Windows PowerShell)

ESP32-S3 使用原生 USB-JTAG CDC，烧录前需将芯片置于下载模式（按住 BOOT 再按 RESET，或使用自动下载电路）。

```powershell
# 先切到用户目录
cd C:\Users\<用户名>

# 拷贝固件
docker cp <容器名>:/workspace/build/bootloader/bootloader.bin .
docker cp <容器名>:/workspace/build/partition_table/partition-table.bin .
docker cp <容器名>:/workspace/build/micropython_bpuppy.bin .

# 烧录 (115200 约 3 分钟, 稳定)
esptool --chip esp32s3 --port COM10 --baud 115200 write-flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 micropython_bpuppy.bin
```

仅拷贝+烧录 (已编译完):
```powershell
cd C:\Users\<用户名>; docker cp <容器名>:/workspace/build/bootloader/bootloader.bin .; docker cp <容器名>:/workspace/build/partition_table/partition-table.bin .; docker cp <容器名>:/workspace/build/micropython_bpuppy.bin .; esptool --chip esp32s3 --port COM10 --baud 115200 write-flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 micropython_bpuppy.bin
```

> **提示:** 看到三行 `Wrote xxx bytes` + `Hash of data verified` 即烧录成功。烧完按 RESET 或重新上电。

## 三、串口连接

- 波特率: **115200**
- 端口: **COM10** (USB-JTAG CDC，直连 USB 即可)
- 工具: PuTTY / Tera Term / VS Code Serial Monitor

> ESP32-S3 原生 USB-JTAG，不需要外接 USB-UART 转接器。插上 USB 线后 Windows 自动识别为串口。

烧录后重启，应看到:
```
============================================
  bPuppy Robot Dog - ESP32-S3 MicroPython
  Build: Jul 10 2026 xx:xx:xx
  WROOM-1 N16R8 | uPy v1.22.1 | IDF v5.1.2
============================================
  Loaded:   servo, uart, motion
Ready.
>>>
```

## 四、MicroPython 命令

### bpuppy_servo — 舵机控制

**舵机命名常量:**

| 常量 | 值 | 含义 |
|------|-----|------|
| `bpuppy_servo.LF_HIP` | 0 | 左前大腿 |
| `bpuppy_servo.LF_KNEE` | 1 | 左前小腿 |
| `bpuppy_servo.LH_HIP` | 2 | 左后大腿 |
| `bpuppy_servo.LH_KNEE` | 3 | 左后小腿 |
| `bpuppy_servo.RF_HIP` | 4 | 右前大腿 |
| `bpuppy_servo.RF_KNEE` | 5 | 右前小腿 |
| `bpuppy_servo.RH_HIP` | 6 | 右后大腿 |
| `bpuppy_servo.RH_KNEE` | 7 | 右后小腿 |

**函数:**

| 函数 | 参数 | 说明 |
|------|------|------|
| `init_all()` | 无 | 按硬件映射初始化全部 8 路舵机 |
| `set_angle(channel, deg)` | 通道号, 角度(0-180) | 设置舵机角度 |
| `get_angle(channel)` | 通道号 | 返回当前角度 (float) |
| `stop()` | 无 | 紧急停止所有舵机 (关闭 PWM) |
| `load_cal()` | 无 | 从 NVS 加载校准值 (开机自动调用) |
| `cal(channel, ref_deg)` | 通道, 参考角 | 校准: 舵机转到 ref_deg°, 存 offset=ref-90 到 NVS |

**舵机校准 (统一接口):**

`cal(channel, ref_deg)` 做两件事:
1. 舵机立刻转到 `ref_deg`（不含补偿），让你当场看腿是否垂直/直角
2. 存 offset = `ref_deg - 90` 到 NVS，之后 `set_angle(90)` 自动补偿

> 反复调 `cal(ch, 94)` → `cal(ch, 93)` → ... 直到腿垂直，最后一次覆盖生效。NVS 持久化。

**示例:**
```python
import bpuppy_servo

# === 校准 (仅需首次，NVS 持久化) ===
bpuppy_motion.emergency_stop()                       # 先停运动任务
bpuppy_servo.init_all()

# 反复调 cal，直到腿垂直
bpuppy_servo.cal(bpuppy_servo.LF_HIP, 95)            # 舵机转到 95°, 还不够垂直
bpuppy_servo.cal(bpuppy_servo.LF_HIP, 93)            # 舵机转到 93°, 垂直了! offset=+3

# 逐条腿校准后恢复运动
bpuppy_motion.resume()
```

### bpuppy_motion — 运动控制

**函数:**

| 函数 | 参数 | 说明 |
|------|------|------|
| `start()` | 无 | 启动 50Hz 运动控制任务 |
| `stand_up()` | 无 | 蹲→站缓动过渡 (C 层, 8舵机同步) |
| `set_gait(gait)` | 步态名称 (str) | 切换步态 |
| `set_params(speed, stride, height)` | 速度, 步幅, 高度 | 调整运动参数 |
| `set_omega(omega)` | 基准角频率 (rad/s) | 调步态整体快慢 (默认 2.0) |
| `cal_ik(L1, L2)` | 大腿长, 小腿长 (mm) | 校准 IK 腿长参数 (默认 40, 40) |
| `set_body_pose(roll, pitch, yaw)` | 横滚, 俯仰, 偏航 (deg) | 调整身体姿态 |
| `set_turn(turn)` | -1~+1 | 转弯系数 |
| `emergency_stop()` | 无 | 急停 |
| `resume()` | 无 | 恢复运动 |

**实测最优参数:**

| 步态 | speed | stride | height | 备注 |
|------|-------|--------|--------|------|
| walk | 2.5 | 70 | 60 | 猫步, 稳而安静 |
| trot | 8 | 0 | 70 | 原地踏步 |
| trot | 8 | 50 | 70 | 小跑行走 |

**步态列表:**

| gait 参数 | 说明 |
|-----------|------|
| `"stand"` | 站立不动 |
| `"walk"` | 猫步 (speed>0前进, speed<0后退) |
| `"trot"` | 小跑 (speed>0前进, speed<0后退) |
| `"go"` | 自适应 (推荐): speed≤4→walk, speed≥6→trot, 4~6 duty/gap 线性插值 |
| `"crawl"` | 慢爬 |
| `"bound"` | 跳跃 (前+后) |
| `"walkturn_l"` | 猫步左转 |
| `"walkturn_r"` | 猫步右转 |
| `"trotturn_l"` | 小跑左转 |
| `"trotturn_r"` | 小跑右转 |
| `"sit"` | 蹲下 |

**身体几何:**

| 参数 | C 代码值 | 说明 |
|------|---------|------|
| L1 (大腿) | 40mm | `ik.h: IK_L1_DEFAULT` |
| L2 (小腿) | 40mm | `ik.h: IK_L2_DEFAULT` |
| 前后髋距 | 120mm | `BODY_HALF_L = 60` |
| 左右髋距 | 118mm | `BODY_HALF_W = 59` |
| 膝角范围 | 10°~170° | `IK_KNEE_MIN ~ IK_KNEE_MAX` |

## 五、快速上手

上电**自动站立**，无需手动指令。站起来后直接操作：

```python
# === 走路 ===
bpuppy_motion.set_params(2.5, 70, 60)     # (speed, stride, height)
bpuppy_motion.set_gait("walk")            # 猫步前进

bpuppy_motion.set_params(-3, 70, 60)      # 猫步后退
bpuppy_motion.set_gait("walk")

bpuppy_motion.set_params(15, 60, 60)      # 小跑
bpuppy_motion.set_gait("trot")

bpuppy_motion.set_params(7, 70, 60)       # 中速自适应
bpuppy_motion.set_gait("go")

# 转向
bpuppy_motion.set_turn(-0.5)              # 左转 -1~+1

# 停下
bpuppy_motion.set_gait("stand")

# 蹲下休息
bpuppy_motion.set_gait("sit")
```

> 关机前先 `set_gait("sit")` 让舵机放松。

### 速查卡片 (可直接粘贴到 REPL)

```python
# ===== 运动控制 =====
import bpuppy_motion
bpuppy_motion.start()                          # 启动运动任务
bpuppy_motion.stand_up()


bpuppy_motion.set_params(2.5, 70, 60)          # (speed, stride, height)
bpuppy_motion.set_gait("walk")                 # 猫步前进

bpuppy_motion.set_gait("trot")                 # 小跑
bpuppy_motion.set_gait("go")                   # 自适应
bpuppy_motion.set_gait("stand")                # 站立
bpuppy_motion.set_gait("sit")                  # 蹲下

bpuppy_motion.set_params(-3, 70, 60)           # 后退 (speed 负号)
bpuppy_motion.set_turn(-0.5)                   # 左转 -1~+1

bpuppy_motion.set_omega(3.0)                   # 加速 (默认 2.0)
bpuppy_motion.set_body_pose(0, 0, 0)           # 身体姿态 (roll, pitch, yaw)
bpuppy_motion.cal_ik(40, 40)                   # 校准腿长 (L1, L2 mm)

bpuppy_motion.emergency_stop()                 # 急停!!
bpuppy_motion.resume()                         # 恢复

# ===== 舵机控制 =====
import bpuppy_servo
bpuppy_servo.init_all()                        # 初始化全部舵机
bpuppy_servo.set_angle(bpuppy_servo.LF_HIP, 90)



bpuppy_servo.LF_HIP   # 0    左前髋
bpuppy_servo.LF_KNEE  # 1    左前膝
bpuppy_servo.LH_HIP   # 2    左后髋
bpuppy_servo.LH_KNEE  # 3    左后膝
bpuppy_servo.RF_HIP   # 4    右前髋
bpuppy_servo.RF_KNEE  # 5    右前膝
bpuppy_servo.RH_HIP   # 6    右后髋
bpuppy_servo.RH_KNEE  # 7    右后膝

bpuppy_servo.init_all()                        # 初始化全部舵机
bpuppy_servo.load_cal()                        # 加载校准值 (开机已自动加载)

bpuppy_servo.set_angle(bpuppy_servo.LF_HIP, 90)
bpuppy_servo.get_angle(bpuppy_servo.LF_HIP)    # 读取当前角度

bpuppy_servo.cal(bpuppy_servo.LF_HIP, 94)     # 舵机转到94°, offset=+4 存NVS
bpuppy_servo.cal(bpuppy_servo.LF_KNEE, 92)    # 反复调直到垂直, 覆盖即可
bpuppy_servo.stop()                            # 关闭 PWM

# ===== 版本 =====
import bpuppy
bpuppy.version()
```


## 六、步态仿真 (PC 端)

在烧录前可用 PC 端 Python 脚本预览和验证步态。位于 `gait_sim/` 目录。

### 依赖

```bash
pip install matplotlib numpy
```

### 用法

```bash
cd gait_sim

# 一键输出 CSV + PNG + GIF
python gait_sim.py

# 弹出图表窗口
python gait_sim.py --show

# 自定义参数
python gait_sim.py --stride 80 --height 70

# 调整动图速度
python gait_sim.py --fps 4

# 只输出特定格式
python gait_sim.py --no-csv --no-png    # 只要 GIF
python gait_sim.py --no-gif --no-png    # 只要 CSV
```

### 输出文件

| 文件 | 内容 |
|------|------|
| `gait_walk.csv` | 单周期 200 帧 × 22 列 (足端坐标 + 关节角度) |
| `gait_walk.png` | t-Z 曲线 + t-X 曲线 + 顶视图快照 + 相位甘特图 |
| `gait_walk.gif` | 顶视图动图 (支撑多边形 + 重心 + 足端轨迹) |

### CSV 列说明

| 列 | 含义 | 坐标系 |
|----|------|--------|
| `step` | 帧序号 | — |
| `g_phase_deg` | 全局相位 (°) | — |
| `{leg}_fx` | 足端前后位置 | x=0 为髋, 正=前 |
| `{leg}_fz` | 足端高度 | z=0 为地面, 正=上 |
| `{leg}_hip` | 髋舵机角度 (°) | 0~180 |
| `{leg}_knee` | 膝舵机角度 (°) | 10~170 |
| `{leg}_swing` | 摆动/支撑 | 1=摆动, 0=支撑 |

### 图表说明

**t-Z 图** — 四足高度随时间变化。z=0 为着地，弧线为抬腿。

**t-X 图** — 四足前后位置随时间变化。x=0 为髋正下方，正=前伸。

**顶视图** — 身体矩形 + 四足位置 + 支撑多边形 (斜线填充) + 重心 (十字)。
- 重心绿色 = 在支撑面内 (稳定)
- 重心红色 = 超出支撑面 (不稳定)
- 三角 = 抬脚 (摆动相)
- 圆点 = 着地 (支撑相)

**相位甘特图** — 四腿摆动/支撑时间分布。红=swing, 绿=stance。

### 修改参数

编辑 `gait_sim.py` 顶部的常量:

```python
L1 = 40.0          # 大腿长度 mm (对应 ik.h)
L2 = 40.0          # 小腿长度 mm
BODY_HALF_L = 60.0 # 前后髋半距 mm
BODY_HALF_W = 59.0 # 左右髋半宽 mm

GAIT_PRESETS = {
    "walk": {"duty": 0.20, "gap": 0.04, "stride": 90.0, "height": 60.0, "lift": 30.0},
}
```
