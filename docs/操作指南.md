# bPuppy 操作指南

## 速查手册

每块**独立拷贝即用**（已含全部 import）。上电已自动站立（舵机 + 运动任务），运动组合块无需再 `start()`。关机前先 `set_gait("crouch")` 让舵机放松。

### ① 常用运动组合

```python
import bpuppy_motion
# 最快
bpuppy_motion.set_params(8.5, 70, 60)
bpuppy_motion.set_lift(45)
bpuppy_motion.set_gait("trot")

# 这也不错
bpuppy_motion.set_params(8.5, 50, 70)
bpuppy_motion.set_lift(30)
bpuppy_motion.set_gait("trot")

# 最稳
bpuppy_motion.set_params(2.5, 70, 70)
bpuppy_motion.set_lift(30)
bpuppy_motion.set_gait("walk")
```

### ② WiFi 图传 + 遥控

```python
import camera_stream
import bpuppy_motion
bpuppy_motion.set_gait("stand")     # 先站立 (start 不会自动停, 避免狗继续运动)
camera_stream.start(stream=True)    # 开启热点 + 视频流 + 网页遥控 → http://192.168.4.1
# camera_stream.start()             # 纯遥控, 不开图传 (默认)
camera_stream.stop()                # 关闭: 热点关闭, 摄像头释放
camera_stream.state()               # 查看状态: "running" / "stopped"
```

### ③ 站立自平衡

```python
import bpuppy_imu
bpuppy_imu.init(0, 3, 14, 0x68)      # ① 先初始化 IMU (AHRS 需先收敛, 上电初期可能需重试)

import time
time.sleep(2)                        # ② 等姿态稳定 (AHRS 收敛)

import balance
balance.start()                      # ③ 三选一 (自动急停)
# balance.start(kp=0.06, ki=0.001, kd=0.5)       # 自定义 PID
```

**辅助 · 循环输出惯导数据:**

```python
import bpuppy_imu
bpuppy_imu.init(0, 3, 14, 0x68)      # 初始化 (幂等)
import time
for i in range(20):
    r, p, y = bpuppy_imu.read_angles()
    print('roll=%.2f pitch=%.2f yaw=%.2f' % (r, p, y))

```

**辅助 · IMU 重新校准:**

```python
import bpuppy_imu
bpuppy_imu.init(0, 3, 14, 0x68)      # 初始化 (幂等)

```

## 一、运动

### 1.1 常用运动组合

三个实测最优方案（完整代码见速查手册①，拷过来就能跑）：

| 方案 | speed | stride | height | lift | gait |
|------|-------|--------|--------|------|------|
| 最快 | 8.5 | 70 | 60 | 45 | trot |
| 这也不错 | 8.5 | 50 | 70 | 30 | trot |
| 最稳 | 2.5 | 70 | 70 | 30 | walk |

> 关机前先 `set_gait("crouch")` 让舵机放松。

### 1.2 运动指令 bpuppy_motion

**函数（调用即用）:**

| 调用示例 | 说明 |
|------|------|
| `bpuppy_motion.start()` | 启动 50Hz 运动任务（自动加载几何参数） |
| `bpuppy_motion.stand_up()` | 蹲→站缓动过渡 (C 层, 8舵机同步) |
| `bpuppy_motion.set_gait("walk")` | 切换步态（见下方步态列表） |
| `bpuppy_motion.emergency_stop()` | 急停 |
| `bpuppy_motion.resume()` | 恢复运动 |
| `bpuppy_motion.show_geometry()` | 查看全部持久化 + 运行时参数 |
| `bpuppy_motion.load_geometry()` | 从 NVS 重新加载持久化参数 |

**运行时参数（掉电丢失，需每次设置）：**

| 调用示例 | 默认值 | 说明 |
|------|--------|------|
| `bpuppy_motion.set_params(2.5, 70, 70)` | 2.5, 0, 70 | (speed, stride, height): 步频 / 步幅+方向 / 高度; speed=0停, stride正=前负=后 |
| `bpuppy_motion.set_lift(30)` | 30 | 抬腿高度 (mm) |
| `bpuppy_motion.set_omega(2.0)` | 2.0 | 基准角频率 (rad/s), 调步态快慢 |
| `bpuppy_motion.set_body_pose(0, 0, 0)` | 0, 0, 0 | (roll, pitch, yaw) 身体倾角 (deg) |
| `bpuppy_motion.set_turn(0)` | 0 | 转弯系数 -1~+1 |

**实测最优参数:**

| 步态 | speed | stride | height | lift | pose | 备注 |
|------|-------|--------|--------|------|------|------|
| walk | 2.5 | 70 | 60~70 | 30 | pitch=-5 | 猫步, 稳而安静 |
| trot | 8~8.5 | 50~70 | 60~70 | 30 | pitch=-3 | 小跑, 最快 |

**步态列表:**

| 调用示例 | 说明 |
|-----------|------|
| `bpuppy_motion.set_gait("stand")` | 站立不动 |
| `bpuppy_motion.set_gait("walk")` | 猫步 (speed>0前进, speed<0后退) |
| `bpuppy_motion.set_gait("trot")` | 小跑 (speed>0前进, speed<0后退) |
| `bpuppy_motion.set_gait("go")` | 自适应 (推荐): speed≤4→walk, speed≥6→trot, 4~6 全参数插值 |
| `bpuppy_motion.set_gait("crouch")` | 蹲伏 (四腿折叠, 关机前放松) |
| `bpuppy_motion.set_gait("sit")` | 猫坐 (前腿撑, 后腿折) |
| `bpuppy_motion.set_gait("play")` | 邀玩 (前低后高 + 4Hz摇臀8次) |
| `bpuppy_motion.set_gait("wave")` | 挥手 (坐下 + 右前膝摆动 3 次, 完成回坐) |

### 1.3 站立自平衡 balance

绕过运动任务，直接舵机控制。增量式 PID，50Hz 闭环。

> ⚠ `start()` 会自动初始化 IMU，但**刚 init 时 AHRS 未收敛就记录零点，可能导致自平衡发散**。建议**先手动初始化 IMU 并等姿态稳定**再启动：

```python
import bpuppy_imu
bpuppy_imu.init(0, 3, 14, 0x68)      # 先初始化 IMU (上电初期可能需重试)

import time
time.sleep(2)                        # 等 AHRS 收敛

import balance
balance.start()                                  # ← 三选一 (默认参数)
# balance.start(kp=0.06, kd=0.2)                 # 自定义 PD
# balance.start(kp=0.06, ki=0.001, kd=0.5)       # 自定义 PID
```

| 参数 | 默认 | 含义 |
|------|------|------|
| kp | 0.06 | 比例增益 |
| ki | 0.0 | 积分增益 |
| kd | 0.43 | 微分增益 |
| deadband | 0.5 | 死区 (°) |
| max_body | 30.0 | 身体倾角上限 (°) |
| height | 60.0 | 目标中心高度 (mm) |

**停止:**

```python
import balance
balance.stop()
```

> `start()` 开头会 `emergency_stop()`，**Ctrl-C 中断后运动处于急停状态**，需手动 `balance.stop()` 或 `bpuppy_motion.resume()` 恢复。

**串口输出:**

```
IMU P+0.1 R-2.4 | Err Pe+0.0 Re+0.0 | Inc iP+0.00 iR+0.00 | Tar Pt+0.0 Rt+0.0
```

| 字段 | 含义 |
|------|------|
| IMU P/R | IMU 姿态角 (Pitch/Roll) |
| Err Pe/Re | 误差 (初始−当前) |
| Inc iP/iR | 本帧补偿增量 |
| Tar Pt/Rt | 目标身体倾角 |

## 二、通信

### 2.1 串口通信 bpuppy_uart

**UART2 (默认通信口)** — GPIO 19=RX, 20=TX，接 CI-33T 语音模块 / micro:bit。

```python
import bpuppy_uart
bpuppy_uart.init(2, 20, 19, 115200)   # UART2, TX=20, RX=19
bpuppy_uart.send(b"hello")            # 发送 bytes
bpuppy_uart.sendline("AT")            # 发送字符串+换行
data = bpuppy_uart.read(64)           # 读取 bytes (非阻塞)
n = bpuppy_uart.any()                 # 缓冲字节数
```

**UART1 (摄像头复用口)** — GPIO 17=TX, 18=RX，**与摄像头 D5/D6 共享引脚，不拍照时可用**。

```python
import bpuppy_uart
bpuppy_uart.u1_init(17, 18, 115200)   # TX=17, RX=18
bpuppy_uart.u1_send(b"hello")
bpuppy_uart.u1_sendline("AT")
data = bpuppy_uart.u1_read(64)
n = bpuppy_uart.u1_any()
```

| 调用示例 | 说明 |
|------|------|
| `bpuppy_uart.init(2, 20, 19, 115200)` | 初始化 UART2 (num, tx, rx, baud) |
| `bpuppy_uart.send(b"hello")` | 发送 bytes 或 str |
| `bpuppy_uart.read(64)` | 读取最多 64 字节 (非阻塞) |
| `bpuppy_uart.any()` | 缓冲中可读字节数 |
| `bpuppy_uart.sendline("AT")` | 发送字符串 + CRLF |
| `bpuppy_uart.stop()` | 停止 UART2 (释放外设, 可重新 init) |
| `bpuppy_uart.u1_init(17, 18, 115200)` | 初始化 UART1 (摄像头复用脚) |
| `bpuppy_uart.u1_send(b"hello")` / `u1_read(n)` / `u1_any()` / `u1_sendline(s)` | UART1 对应操作 |
| `bpuppy_uart.u1_stop()` | 停止 UART1 (释放外设, 可重新 init) |

> 两者均**手动初始化**，上电不自动启动（避免与摄像头抢引脚）。

### 2.2 WiFi 实时图传 + 网页遥控器 camera_stream

`camera_stream.py` 同时提供两个功能：MJPEG 实时视频流 + 网页遥控器。

**启动:**

```python
import camera_stream
import bpuppy_motion
bpuppy_motion.set_gait("stand")     # 先站立, 再开图传 (start 不会自动停)
camera_stream.start(stream=True)    # stream=True 开图传; 默认 start() 纯遥控不开图传
# → 串口打印: camera_stream: started — http://192.168.4.1
```

ESP32-S3 开启 WiFi 热点（热点名 `bPuppy_XXXX`，XXXX=MAC 后四位）。**上电已自动开启纯遥控**（不占摄像头 GPIO17/18）；`start(stream=True)` 才初始化摄像头（SVGA 800×600 JPEG）。**运行时可在网页点「图传 开/关」切换**，遥控始终可用。

**手机/PC 连接:**

| 步骤 | 内容 |
|------|------|
| 1. 打开 WiFi | 搜索 `bPuppy_XXXX` 热点 (XXXX = MAC 后四位) |
| 2. 输入密码 | `12345678` |
| 3. 打开浏览器 | 输入 `http://192.168.4.1` |
| 4. 看到画面 | 实时视频流 (~10-15fps) + 遥控界面 |

**网页遥控器功能:**

| 控件 | 操作 | 效果 |
|------|------|------|
| 速度滑块 | 拖动 0~10 | 调步频 |
| 方向按钮 (8方向) | 点击 | 转向 + 前进/后退 |
| 停 | 点击 | 立即站立 |
| 站立/坐下/蹲下 | 点击 | 切换姿态 |
| 玩 | 点击 | 邀玩动作 (前低后高+摇臀) |
| 挥手 | 点击 | 坐下 + 右前膝摆动 3 次 |
| 图传 开/关 | 点击 | 运行时开关视频流 (页面刷新生效) |

**停止:**

```python
import camera_stream
camera_stream.stop()
# → 串口打印: camera_stream: stopped
# 热点关闭, 摄像头释放
```

**切换摄像头用途:**

```python
# 图传 → 拍照
camera_stream.stop()
import camera_serial
camera_serial.snap()

# 拍照 → 图传
import camera_stream
camera_stream.start(stream=True)
```

`start(stream=True)` 会自动 `init_adv()` 初始化摄像头，`stop()` 会自动 `deinit()` 释放。两个功能互相切换无需手动管摄像头。

**查看状态:**

```python
import camera_stream
camera_stream.state()  # → "running" 或 "stopped"
```

**自定义热点:**

```python
import camera_stream
camera_stream.start(ssid="MyDog", password="mypassword", stream=True)
```

### 2.3 蓝牙遥控 ble_hiwonder

Hiwonder Wonderbot App 蓝牙遥控，NimBLE GATT（FFE0/FFE1/FFE2），设备名 `mechdog_XX`。

```python
import ble_hiwonder
import bpuppy_motion
import _thread
bpuppy_motion.set_gait("stand")                  # 先站立, 再开广播 (构造不会自动停)
ble = ble_hiwonder.HiwonderBLE()                 # 构造即开启广播
_thread.start_new_thread(ble_hiwonder.run_ble_task, (ble, 50))
```

| 调用示例 | 说明 |
|------|------|
| `ble.connected()` | 是否已连接 (bool) |
| `ble.send("CMD|0|mechdog|$")` | 发送数据给 App |
| `ble.stop()` | 停止广播 + 断开连接（可再 `start()`） |

- App: Hiwonder **Wonderbot**，连接 `mechdog_XX` 设备
- 颜色滑块调速：左=0，右=12
- `stop()` 后 NimBLE 栈保留，可重新 `start()` 广播

> 与 WiFi 遥控（camera_stream）**完全独立**：蓝牙走 NimBLE，WiFi 走热点 HTTP。

## 三、视觉

### 3.1 摄像头操作 bpuppy_camera

**拍照:**

```python
import bpuppy_camera

# 初始化（上电后首次需手动 init）
bpuppy_camera.init()

# 拍照 → 返回 (data, width, height, format)
data, w, h, fmt = bpuppy_camera.capture()

bpuppy_camera.deinit()
```

**格式切换:**

默认 `init()` 输出 JPEG 1600×1200。如需其他格式或分辨率：

```python
import bpuppy_camera
# QVGA 320×240 RGB565（色球识别用）
bpuppy_camera.init_adv(bpuppy_camera.QVGA, 0, 2, 20000000, bpuppy_camera.RGB565)

# SVGA 800×600 JPEG（WiFi 图传用）
bpuppy_camera.init_adv(bpuppy_camera.SVGA, 10, 2, 20000000, bpuppy_camera.JPEG)
```

| 分辨率 | 常量 | 像素 |
|--------|------|------|
| 160×120 | `QQVGA` | — |
| 320×240 | `QVGA` | — |
| 640×480 | `VGA` | — |
| 800×600 | `SVGA` | — |
| 1024×768 | `XGA` | — |
| 1600×1200 | `UXGA` | 默认 |

| 格式 | 常量 | 用途 |
|------|------|------|
| JPEG | `JPEG` (4) | 拍照/图传，硬件编码 |
| RGB565 | `RGB565` (1) | 图像识别，原始像素 |
| GRAYSCALE | `GRAYSCALE` (5) | 灰度图 |

**已知问题:**

- 初始化后前几帧可能是旧画面（双缓冲残留），`camera_serial.snap()` 已自动丢弃前 3 帧
- 图像上下颠倒：已在驱动中通过 `set_vflip(1)` 修正

## 四、设置与校准

### 4.1 舵机校准 bpuppy_servo

**舵机命名常量:**

| 常量 | 值 | 含义 |
|------|-----|------|
| `bpuppy_servo.LF_HIP` | 0 | 左前大腿 |
| `bpuppy_servo.LF_KNEE` | 1 | 左前小腿 |
| `bpuppy_servo.LH_HIP` | 2 | 左后大腿 |
| `bpuppy_servo.LH_KNEE` | 3 | 左后小腿 |
| `bpuppy_servo.RF_HIP` | 4 | 右前大腿 |
| `bpuppy_servo.RF_KNEE` | 5 | 右前小腿 |
| `bpuppy_servo.RH_HIP` | 6 | 右后大腿 |
| `bpuppy_servo.RH_KNEE` | 7 | 右后小腿 |

**函数（调用即用）:**

| 调用示例 | 说明 |
|------|------|
| `bpuppy_servo.init_all()` | 按硬件映射初始化全部 8 路舵机 |
| `bpuppy_servo.set_angle(0, 90)` | (通道, 角度 0-180) 设置舵机角度 |
| `bpuppy_servo.get_angle(0)` | (通道) 返回当前角度 (float) |
| `bpuppy_servo.stop()` | 紧急停止所有舵机 (关闭 PWM) |
| `bpuppy_servo.cal(0, 90)` ★ | (通道, 参考角) 校准存 NVS |
| `bpuppy_servo.get_cal(0)` | (通道) 读取校准参考角 (float) |
| `bpuppy_servo.load_cal()` ★ | 从 NVS 加载校准值 (开机自动调用) |

**校准说明:**

`cal(ch, ref)` → 舵机转到 `ref`° 当场验证 + 存 `offset = ref - 90` 到 NVS。之后每次 `set_angle(90)` 都自动加这个 offset，腿自然垂直。反复调、覆盖生效。`get_cal(ch)` 查看当前值。

> 方向约定（髋 0/90/180 指向、膝左右镜像）见 README「舵机角度标定」表。

### 4.2 持久化参数（★NVS，掉电保留）

| 组 | 调用示例 | 默认值 |
|----|------|--------|
| 几何 | `bpuppy_motion.cal_ik(40, 45)` ★ | 大腿 40, 小腿 45 (mm) |
| 几何 | `bpuppy_motion.set_body_dims(62.5, 59)` ★ | 前后半距 62.5, 左右半宽 59 (mm) |
| 几何 | `bpuppy_motion.set_joint_limits(0, 180, 10, 170)` ★ | 髋 0~180, 膝 10~170 (deg) |
| 舵机 | `bpuppy_servo.cal(ch, 90)` ★ | 8 路校准参考角 (deg) |
| 重心 | `bpuppy_motion.set_center(0)` ★ | 脚中位偏移 (mm)，正=前移 |

> 以上 9+8=17 个参数设定后自动写入 NVS，`motion.start()` 自动恢复。`show_geometry()` 可查看全部。无 NVS 数据时回退 `ik.h` 宏默认值。

### 4.3 校准流程（首次或换硬件后）

```python
import bpuppy_motion
import bpuppy_servo

# === 几何参数 — 通常无需改动 ===
bpuppy_motion.cal_ik(40, 45)                     # 腿长 (L1, L2 mm)
bpuppy_motion.set_body_dims(62.5, 59)            # 髋距 (前后半距, 左右半宽 mm)
bpuppy_motion.set_joint_limits(0, 180, 10, 170)  # 限位 (髋min/max, 膝min/max deg)

# === 舵机校准 — 逐腿操作 ===
bpuppy_motion.emergency_stop()                   # 先停运动
bpuppy_servo.cal(bpuppy_servo.LF_HIP, 95)        # 反复调 cal 直到腿垂直, 覆盖即可
# ... 逐条校准其余 7 路 ...
bpuppy_motion.resume()                           # 恢复运动

# === 重心偏移 — 走起来后微调 ===
bpuppy_motion.set_center(0)                      # 正值=脚前移 (重心后移)

# 查看全部
bpuppy_motion.show_geometry()
```

## 五、传感器与姿态

### 5.1 IMU 调试 bpuppy_imu

> 手动初始化: `bpuppy_imu.init(0, 3, 14, 0x68)`。balance / set_heading / calib_mag 的 `start()` 会自动启动，无需手动。停止: `bpuppy_imu.stop()`（停 AHRS 任务，可重新 init）。

**查看原始数据 (加速度/陀螺/磁力计/温度):**

```python
import bpuppy_imu
bpuppy_imu.init(0, 3, 14, 0x68)      # 初始化 (幂等)
import time
for i in range(20):
    a, g, m, t = bpuppy_imu.read_raw()
    print('acc=%.2f %.2f %.2f  gyro=%.2f %.2f %.2f  mag=%.1f %.1f %.1f  temp=%.1f' %
          (a[0],a[1],a[2], g[0],g[1],g[2], m[0],m[1],m[2], t))
    time.sleep(0.3)
```

**查看姿态角 (roll, pitch, yaw):**

```python
import bpuppy_imu
bpuppy_imu.init(0, 3, 14, 0x68)      # 初始化 (幂等)
import time
for i in range(20):
    r, p, y = bpuppy_imu.read_angles()
    print('roll=%.2f pitch=%.2f yaw=%.2f' % (r, p, y))
    time.sleep(0.5)
```

### 5.2 IMU 校准（陀螺 + 加速度计）

```python
import bpuppy_imu
bpuppy_imu.init(0, 3, 14, 0x68)      # 初始化 (幂等)
bpuppy_imu.calibrate(300)            # 放平别动, 采 300 样本 (~3 秒)
```

- 校准内容: 陀螺仪三轴零偏（消除静止漂移）+ 加速度计 Z 轴 1g 偏差补偿
- 要求: 放平静止, 不要移动
- 何时需要: 新硬件 / 更换后, 或姿态角漂移明显时
- 校准数据存入 NVS, 重启自动恢复, 无需每次校准

### 5.3 磁力计校准 calib_mag

3D 椭球拟合引导式校准。拿起机器狗，按提示分三轴（Roll / Pitch / Yaw）旋转，实时显示覆盖进度，全部达标后自动拟合并存入 NVS。`start()` 会自动初始化 IMU。

```python
import calib_mag
calib_mag.start()
```

各轴覆盖目标 60μT（Yaw 需转满 360°）。校准数据掉电保留，`imu_init()` 时自动恢复。

### 5.4 航向锁定 set_heading

保持指定航向（默认 57°），通过 `set_turn` 转向。`start()` 会自动初始化 IMU。

```python
import set_heading
set_heading.start(57)         # 锁定 57° 方向 (缺省 57)
set_heading.stop()            # 停止
```

### 5.5 电池电压 bpuppy_adc

7.4V LiPo 经分压 (33k+10k) 接 GPIO 38 (ADC1_CH2)，软件乘系数换算。

```python
import bpuppy_adc
bpuppy_adc.init()             # GPIO 38, 11dB 衰减 (~0-3.1V)
mv = bpuppy_adc.read_mv()     # 毫伏
battery_v = mv * 4.3 / 1000   # 电池电压 (V)
```

| 调用示例 | 说明 |
|------|------|
| `bpuppy_adc.init()` | 初始化 ADC1_CH2 |
| `bpuppy_adc.read_mv()` | 采样点电压 (mV) |
| `bpuppy_adc.read_raw()` | 原始 ADC 值 (0-4095) |
| `bpuppy_adc.stop()` | 停止 ADC (read 返回 -1, 可重新 init) |

## 六、PC 端工具

### 6.1 步态仿真 (PC 端)

在烧录前可用 PC 端 Python 脚本预览和验证步态。位于 `gait_sim/` 目录。

**依赖:**

```bash
pip install matplotlib numpy
```

**用法:**

```bash
cd gait_sim

# 一键输出 CSV + PNG + GIF
python gait_sim.py

# 弹出图表窗口
python gait_sim.py --show

# 自定义参数
python gait_sim.py --stride 80 --height 70

# 调整动图速度
python gait_sim.py --fps 4

# 只输出特定格式
python gait_sim.py --no-csv --no-png    # 只要 GIF
python gait_sim.py --no-gif --no-png    # 只要 CSV
```

**输出文件:**

| 文件 | 内容 |
|------|------|
| `gait_walk.csv` | 单周期 200 帧 × 22 列 (足端坐标 + 关节角度) |
| `gait_walk.png` | t-Z 曲线 + t-X 曲线 + 顶视图快照 + 相位甘特图 |
| `gait_walk.gif` | 顶视图动图 (支撑多边形 + 重心 + 足端轨迹) |

**CSV 列说明:**

| 列 | 含义 | 坐标系 |
|----|------|--------|
| `step` | 帧序号 | — |
| `g_phase_deg` | 全局相位 (°) | — |
| `{leg}_fx` | 足端前后位置 | x=0 为髋, 正=前 |
| `{leg}_fz` | 足端高度 | z=0 为地面, 正=上 |
| `{leg}_hip` | 髋舵机角度 (°) | 0~180 |
| `{leg}_knee` | 膝舵机角度 (°) | 10~170 |
| `{leg}_swing` | 摆动/支撑 | 1=摆动, 0=支撑 |

**图表说明:**

**t-Z 图** — 四足高度随时间变化。z=0 为着地，弧线为抬腿。

**t-X 图** — 四足前后位置随时间变化。x=0 为髋正下方，正=前伸。

**顶视图** — 身体矩形 + 四足位置 + 支撑多边形 (斜线填充) + 重心 (十字)。
- 重心绿色 = 在支撑面内 (稳定)
- 重心红色 = 超出支撑面 (不稳定)
- 三角 = 抬脚 (摆动相)
- 圆点 = 着地 (支撑相)

**相位甘特图** — 四腿摆动/支撑时间分布。红=swing, 绿=stance。

**修改参数:**

编辑 `gait_sim.py` 顶部的常量:

```python
L1 = 40.0          # 大腿长度 mm (对应 ik.h)
L2 = 45.0          # 小腿长度 mm
BODY_HALF_L = 62.5 # 前后髋半距 mm
BODY_HALF_W = 59.0 # 左右髋半宽 mm
GAIT_PRESETS = {
    "walk": {"duty": 0.20, "gap": 0.02, "stride": 70.0, "height": 60.0, "lift": 30.0},
}
```
