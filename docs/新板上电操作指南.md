# bPuppy 新板上电操作指南

> 🌐 [English](getting-started.en.md)

PCB焊接完成，整机装配完成后，还有一些必要的烧录与校准工作需要完成。准确的顺序是：
烧固件 → 传文件 → 校准


## 0. 准备工作

**1）下载软件工具bTool**
[⬇ 下载 bTool.exe](https://github.com/bobyuhit/bTool/releases/latest/download/bTool.exe)

**2）下载固件与micropython程序文件**
**bPuppy系统固件**
| 文件 | 作用 | 烧写地址 |
|---|---|---|
| [micropython_bpuppy.bin](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/firmware/micropython_bpuppy.bin) | 应用程序，**每次都要烧** | `0x10000` |
| [bootloader.bin](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/firmware/bootloader.bin) | 引导程序，首次上电烧写 / 改过 bootloader后烧写 | `0x0` |
| [partition-table.bin](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/firmware/partition-table.bin) | 分区表，首次上电烧写 / 改过分区表后烧写 | `0x8000` |

**可根据需要，选择性上传到单片机系统VFS的 3 个 .py 文件**（上传到单片机系统的根目录 / VFS）:

| 文件 | 作用 |
|---|---|
| [pwm_ext_on.py](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/mpy_modules/pwm_ext_on.py) | 开机自动启用扩展舵机接口功能 |
| [camera_on.py](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/mpy_modules/camera_on.py) | 开机自动开网页图传功能 |
| [batt.py](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/mpy_modules/batt.py) | 电池采样标定工具 |

**3）硬件材料：**
准备USB-A转Type-C数据线一条。连接电脑与bPuppy控制板上的烧录用Type-C口。控制板上共有两个Type-C 插口，选择板上`◄CODE`字符指向的那个口。
⚠注意此时不要打开机器狗的电源开关。

**4）串口连接**
观察和选择当前连接控制板的串口号。
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/16.png)
点击连接按钮。如果成功，串口右上侧的图标就会由叉变成勾，窗口底部状态栏中也会出现“已连接”。

## 1. 固件烧录
1. 在bTool软件界面，观察窗口右上角确保串口连接正常（打勾），观察窗口左侧页面选择栏，确保处于下载烧写页面（向下的箭头图标）。
2. 点击添加固件。首次烧写时，把上一步骤下载的：`micropython_bpuppy.bin，bootloader.bin，partition-table.bin`都导入进来。日常升级只选 **`micropython_bpuppy.bin`**
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/17.png)
3. 点击**开始烧写**按钮。
- ⚠ 除了新电路板上电后第一次烧写外，后续烧写统统不要勾选「先擦除整片 Flash」，因为会擦除系统的标定数据。

✅ **通过**：烧写日志最后显示如下

```
✓ 烧写完成
[串口已重新打开]
```

## 2. 上传文件
bPuppy的主控采用esp32-S3模块。模块上的非易失存储空间被划分为三个部分：**程序空间，VFS空间和NVS空间**，分别用来存储底层程序，用户程序(.py文件)和系统配置数据。
bPuppy控制系统是C语言和micropython混合编程，用户可以自行编写micropython程序，并上传到VFS空间。
推荐上传到VFS的.py文件(自选)：

| 文件 | 作用 | 不传会怎样 |
|---|---|---|
| `mpy_modules/pwm_ext_on.py` | 开机启用扩展舵机（宏 `EXT1/EXT2/EXT3`，默认只开 `EXT2`） | 扩展舵机口读写时报「未启用」 |
| `mpy_modules/camera_on.py` | 开机自动开WiFi网页遥控和图传 | WiFi遥控和图传功能被关闭，但更省电 |
| `mpy_modules/batt.py` | 首次上电时使用的电池标定专用工具| 无影响 |

步骤：

1. 在bTool软件界面，观察窗口右上角确保串口连接正常（打勾），观察窗口左侧页面选择栏，选择**文件管理**（文件夹图标）。
2. 本地文件选中刚刚下载的三个.py文件所在目录。
3. 在左边文件列表中选中文件，点 **`上传 →`**
4. 确保文件已经达到右边设备VFS文件列表中。
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/18.png)
5. 从机器狗上拔掉USB数据线。

## 3. 舵机标定

本机采用极低成本的MG90S舵机，负载能力和精度都很有限。要想达到更好的运行效果，必须要尽量准确地完成舵机的标定。标定后的数据会在NVS存储空间中长效保存。
为了让舵机运行精度更高，对bPuppy的每个关节舵机进行 **0°/90°/180°** 三点标定。在舵机的控制算法中，会根据标定的结果，采用插值法来让舵机的输出角度更精确。

### 3.1 舵机角度描述的约定
首先，本系统中关于舵机角度的约定如下表：

| 关节 | 通道 | 0° | 90° | 180° |
|---|---|---|---|---|
| 左前大腿 `LF_HIP` | 0 | 指向前方 | 指向下方 | 指向后方 |
| 左前小腿 `LF_KNEE` | 1 | 与大腿重叠 | 向前，跟大腿成直角 | 伸直，跟大腿一条直线 |
| 左后大腿 `LH_HIP` | 2 | 指向前方 | 指向下方 | 指向后方 |
| 左后小腿 `LH_KNEE` | 3 | 伸直，跟大腿一条直线 | 向后，跟大腿成直角 | 与大腿重叠 |
| 右前大腿 `RF_HIP` | 4 | 指向后方 | 指向下方 | 指向前方 |
| 右前小腿 `RF_KNEE` | 5 | 伸直，跟大腿一条直线 | 向前，跟大腿成直角 | 与大腿重叠 |
| 右后大腿 `RH_HIP` | 6 | 指向后方 | 指向下方 | 指向前方 |
| 右后小腿 `RH_KNEE` | 7 | 与大腿重叠 | 向后，跟大腿成直角 | 伸直，跟大腿一条直线 |
> 1) **左前大腿**指代左前腿髋关节舵机，**右后小腿**指代右后腿膝关节舵机。其他以此类推。
> 2) **指向前方**的意思是指向狗头的方向，与地面平行；**指向后方**的意思是指向狗尾的方向，与地面平行；**指向下方**的意思是指向地心，与地面垂直。
> 3) 描述小腿指向时，默认该大腿此时正处于90度竖直向下状态。

下图描述了所有关节都设为90°时的状态：
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/19.png)

### 3.2 初步对准
1) 确保机器狗电源开关**关闭**。松开机器狗上所有连接舵机与大腿的四颗螺丝，把腿从髋关节舵机上取下，注意不要拔线，并认清哪个腿对应哪个髋关节舵机。
2) 把机器狗开关拨到ON，打开机器狗电源。注意：开机瞬间机器狗的腿会乱动一下。
3) 插上USB数据线，机器狗连接电脑。打开bTool软件，找到机器狗的串口，并点击插头图标按钮，连接机器狗。
4) bTool软件窗口左侧的页面选择栏，找到**小狗图标**，点击进入机器狗设置页。点击**舵机关节校准**，在弹出的页面上点击**一键全部转到90°**。这时机器狗腿会乱动一下。
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/20.png)
5) 不要关电源。按照3.1节图中的角度，拆解并重新安装好所有的髋关节和膝关节舵机。
- ⚠ 这时候舵机是锁定角度的，在安装过程中不要用力拧舵机轴，否则会损坏舵机。
6) 因为舵机轴的齿数很少，所以实际上所有关节都无法通过安装准确地达到90°。只需要做到尽量靠近90°，下一步还会进行微调。

### 3.3 舵机微调
安装好后，就要对舵机进行三点标定工作了。
1) 从左前腿髋关节开始。观察到此时大腿跟机身之间的夹角不是标准90°，而是稍微有点歪。
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/21.png)
2) bTool关节校准页面下，选择**左前大腿**，基准角**90°**，尝试着给**实际角度**增加5°，点击**设置**。
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/22.png)
3) 观察左前腿髋关节的角度变化，是**更远离**垂线了呢，还是**更接近**垂线了？
根据情况，继续反复修改**实际角度**并点击**设置**，直到目测左前腿髋关节完全垂直于机身，指向地面。轻轻晃动左前大腿，间隙前后均匀。
4) 这样，左前腿髋关节的90°标定就完成了。
5) 接下来，进行左前腿髋关节的0°标定。在bTool上选择基准角0°，然后点击**设置**。这时候左前大腿会转动并指向前方。但是依然会有角度偏差。
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/23.png)
6) 同样的步骤，反复调整**实际角度**并点击**设置**。直到左前大腿完全与机身平行，指向前方。
7) 参照**3.1 舵机角度描述**中的约定，继续调整所有关节的三个标定点位置。
![示例图片](https://raw.githubusercontent.com/bobyuhit/bPuppy/master/docs/PIC/24.png)
- ⚠ 需要严格对照**3.1 舵机角度描述**的约定进行设置。
8) 8个舵机都调整完毕后，关闭**bTool舵机关节校准**页面。

## 4. IMU与磁力计校准
### 4.1 IMU
1) bTool机器狗设置界面有IMU校准按钮，点击进入按提示校准即可。
2) 校准前，必须把机器狗摆放在稳定的平面上，目测机身角度越平越好。
3) 校准过程中，不要移动机器狗。

### 4.2 磁力计校准

1) bTool机器狗设置界面有磁力计校准按钮，点击进入按提示校准即可。
2) 校准开始后，拿起机器狗，遵循提示进行旋转（左右倾斜 → 前后倾斜 → 水平转满 360°），样本采集足够后，软件会提示采集成功。
✅ **通过**：`✓ 校准完成! 残差: 0.0xxx`
> * 残差 **<0.05**: 好
> * 残差 **>0.08** 会警告质量差 → 重新标一次

到此，新板所需要进行的设置已经完成了。
